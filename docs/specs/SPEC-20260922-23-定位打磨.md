## §1 现状实测（2026-09-28，真机 + 源码双向核对）

**实测问题**：15% 金色叠在「自带底色的气泡」上几乎不可见（气泡本体不透明，容器底色只从气泡四周缝隙漏出）——即「有高亮但看不见」。

## §2 目标（3 项）

1. **闪光定档可见**：让目标消息在真机上一眼可辨（**不刺眼**是本项目一贯口径，参照 SPEC-20）。
2. **句级定位**：跳过去后把**当前搜索关键词**在该条消息里标出来（复用 `highlight_plain_text` 浅档 token + 下划线）⇒ 与搜索结果语义一致；`LOCATE_FLASH_MS`（2400ms，理由见 §10 F23-4）后与闪光一并恢复。
3. **平滑滚动**：`ensureWidgetVisible` 改动画滚动，且**受既有开关约束**（`REZERO_DISABLE_UI_MOTION=1` ⇒ 瞬跳）。

## §3 非目标

- 不改搜索结果/浮层的高亮 token 与浮层布局；
- 不动 `[SPEC-22]` 拆包范围（本 SPEC 全部落在 `gui.py` 的定位函数 + token/theme 两处）；
- **不做**历史浮层的 UIA/无障碍暴露（真机实测：浮层整块不在 UIA 树，`📍` 亦不响应合成点击 ⇒ 自动化盲区）——记入 `INDEX.md` 债务观察，另立项；

**为何不与搜索浅档 0.42 统一**（审计问）：**作用面与面积都不同** —— ① 搜索高亮压在**文字下**，α 直接影响可读性（SPEC-20 实测定 0.42 保对比度 9.28:1）；② 定位底色在**气泡之外**（气泡不透明，文字对比完全不受影响），α 只决定「看不看得见」，且覆盖**整条消息**（面积是词级的几十倍）⇒ 底色取更弱一档、把「引起注意」交给**描边**。两者**色相同源**（`255,205,96`），α 不同有据可依。

**F23-3（阻塞）· 滚动动画与截图基线** —— ✅ 闭环：新增基线面**一律捕捉终态**（`REZERO_DISABLE_UI_MOTION=1` + 滚动位置直接 `setValue` + 闪光/句级标记直接应用，不经动画）；offstage 动画时序不稳定，**不进基线**；动画本身由**真机门禁**覆盖。测试侧不 sleep：恢复函数抽成 `_clear_locate_marks()`，用例直接调用（`LOCATE_FLASH_MS` 只影响真机观感）。

**F23-4（建议）· `LOCATE_FLASH_MS = 2400` 的理由（留档）** —— 感知链：浮层关闭 → 聊天区滚动动画（≈220ms）→ 视觉重心落到目标消息，净观察窗口 ≈ 2.0s − 0.4s = 1.6s 偏紧；2400ms 把净窗口拉回 **≈1.9s**（仍属「一闪」量级，不进入常驻状态）。真机可再调（模块常量，一处改）。
