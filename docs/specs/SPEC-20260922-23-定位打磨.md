# 步 10：历史定位打磨（闪光定档 + 句级定位 + 平滑滚动）

## §1 现状实测（2026-09-28，真机 + 源码双向核对）

定位链路**已存在**（V10.12，非新功能）：`HistoryItemWidget 📍 → locate_clicked(msg_id) → HistoryOverlay.locate_requested → TwinChatApp._locate_message`：

| 环节 | 现状 | 位置 |
|---|---|---|
| 跳转 | 关浮层 → 按 `message_id` 找 `ChatMessageWidget` → `ensureWidgetVisible()` **瞬跳** → 输入框取焦 | `gui.py:_locate_message` |
| 高亮 | 整条消息容器套 `theme.locate_highlight()` = `COLORS["locate_highlight"]` = **`rgba(255,215,0,0.15)`** → **2s 后 `setStyleSheet("")`** | `gui.py:_highlight_widget` · `design_tokens.py:52` |
| 句级 | **无**——不标命中词（搜索结果那侧才有下划线） | — |
| 失败 | 消息已挤出可见范围 → transient 提示 + DB 摘要（不污染主聊天流） | `gui.py:_locate_message` 尾段 |

**实测问题**：15% 金色叠在「自带底色的气泡」上几乎不可见（气泡本体不透明，容器底色只从气泡四周缝隙漏出）——即「有高亮但看不见」。

## §2 目标（3 项）

1. **闪光定档可见**：让目标消息在真机上一眼可辨（**不刺眼**是本项目一贯口径，参照 SPEC-20）。
2. **句级定位**：跳过去后把**当前搜索关键词**在该条消息里标出来（复用 `highlight_plain_text` 浅档 token + 下划线）⇒ 与搜索结果语义一致；2s 后与闪光一并恢复。
3. **平滑滚动**：`ensureWidgetVisible` 改动画滚动，且**受既有开关约束**（`REZERO_DISABLE_UI_MOTION=1` ⇒ 瞬跳）。

## §3 非目标

- 不改搜索结果/浮层的高亮 token 与浮层布局；
- 不动 `[SPEC-22]` 拆包范围（本 SPEC 全部落在 `gui.py` 的定位函数 + token/theme 两处）；
- **不做**历史浮层的 UIA/无障碍暴露（真机实测：浮层整块不在 UIA 树，`📍` 亦不响应合成点击 ⇒ 自动化盲区）——记入 `INDEX.md` 债务观察，另立项；
- 不改 2 秒时长语义（改为常量便于调参，默认仍 2s 级别）。

## §4 设计（参数表）

| 项 | 现值 | 候选（**先打包一版真机看**，同 SPEC-20 流程） |
|---|---|---|
| 容器底色 `locate_highlight` | `rgba(255,215,0,0.15)` | `rgba(255,205,96,0.28)`（与搜索浅档同源暖黄，降饱和提可见度） |
| 描边 | 无 | `1px solid rgba(255,205,96,0.55)` + `border-radius` 保持 `RADIUS['small']` |
| 时长 | 2000ms | `LOCATE_FLASH_MS = 2400`（模块常量，测试可直接调用恢复函数，不靠 sleep） |
| 句级标记 | 无 | 目标气泡 `QLabel#bubble_text` 走 `highlight_plain_text(content, keyword)`（**light 档**，含下划线）；原文存 `w._locate_hit_text` 供恢复 |
| 恢复 | `setStyleSheet("")` | 恢复为空字符串 + 若句级标记存在则先还原原文；**对已销毁 widget 做保护**（现有 lambda 无守卫，widget 先被删会在定时器里抛异常） |
| 滚动 | 瞬跳 | `QPropertyAnimation(verticalScrollBar, "value")`；`REZERO_DISABLE_UI_MOTION=1` ⇒ 直接 `setValue` |

**接口变化**：`HistoryOverlay.locate_requested` 由 `Signal(int)` → `Signal(int, str)`（多带 keyword；内部信号，非公开 API）。无 keyword（未搜索直接点）⇒ 只闪光，不标句。

**实现要点（复用既有机制，不新建真源）**：
- 关键词透传：浮层 emit 时带 `self._search_input.text().strip()`；
- 句级标记复用聊天区搜索那套：`w._bubble.findChild(QLabel, "bubble_text")`（`highlight_hits()` 已验证可行）；
- 恢复函数抽成 `_clear_locate_marks(widget)`，闪光定时器与「下一次定位」都调它（幂等）。
