# SPEC-20260922-28：`_AMBIENT_REGISTRY` 未定义修复（L1）

- **SPEC-ID**：SPEC-20260922-28
- **级别**：L1（局部 Bug 修复，不改接口）
- **等待批准**：**是**
- **来源**：SPEC-25 真机核验发现的既有缺陷（审计 2026-10-10 建议独立小 SPEC）

## §1 缺陷（实锤）

启动日志每轮出现：`偶发一句选取失败: name '_AMBIENT_REGISTRY' is not defined`（`dist/data/gui.log`），
导致轻氛围「偶发一句」**恒定降级为「无」**（功能长期静默失效）。

**根因（迁移遗漏）**：函数 `_get_ambient_registry()` 在 `ui/flags.py:48`（SPEC-22 S1a 搬移产物）内使用
`global _AMBIENT_REGISTRY`，但该模块级变量**仍留在** `gui.py:56`（`_AMBIENT_REGISTRY: Optional[dict] = None`）
⇒ `ui/flags.py` 内首次读取即 `NameError` ⇒ 被 `except` 吞掉 ⇒ 恒降级。

## §2 目标

- 在 `ui/flags.py` 补模块级 `_AMBIENT_REGISTRY: Optional[dict] = None`（与 `_name_hint_shown` 同区）；
- `gui.py` 处改为 re-export 或删除（保持 `gui._AMBIENT_REGISTRY` 可导入 ⇒ 接口零变化）；
- 加回归用例：`_get_ambient_registry()` 返回 dict（且非首次调用返回同一对象=单例）。

## §3 非目标

不动注册表内容/加载路径；不改「偶发一句」的选型逻辑与冷却。

## §4 需要读取/修改的文件

@ui/flags.py（补定义）· @gui.py（re-export/删旧定义）· @tests/test_v14_11_experience.py（追加断言，先核对其现有 103 行用例为何未抓到）

## §5 接口 / 数据

零变化（纯内部变量归位）。

## §6 测试方式

全量 pytest + 冒烟 + 隔离；另**真机复核**：启动后 `dist/data/gui.log` 不再出现该错误行、且轻氛围行出现「偶发一句: X」。
