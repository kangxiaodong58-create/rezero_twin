### F20-4（建议）：rgba 探针的具体做法（写死进本 SPEC）

1. 构造 `QLabel`（RichText）文本：`<span style="background-color: rgba(255,0,0,0.5)">test</span>`；
2. 渲染到**白底** `QPixmap`（`QLabel.grab()`）；
3. 取 span 区域内像素；
4. **判定**：像素 ≈ `(255,128,128)`（= 半透明生了效）→ PASS；≈ `(255,0,0)`（纯红：alpha 被忽略）→ 退化到「按底预乘的不透明色」并在本 SPEC 附录记录实测结论。

## 设计（取值写死，不留实现自由发挥）

1. **token 改为一行四键**（`design_tokens.py`，扁平键，见上「结构选择」）：

   ```python
   "search_hit_light_bg": "rgba(255,205,96,0.42)",  # 聊天区浅底气泡
   "search_hit_light_fg": "",                        # 空串 = 不覆盖文字色（对比 9.28:1，见 F20-3）
   "search_hit_dark_bg":  "rgba(255,200,80,0.22)",   # 历史浮层深底卡片
   "search_hit_dark_fg":  "#FFE6B0",                 # 深档必须提亮（原色仅 3.11:1，不达标）
   ```

   并**删除**旧 `COLORS["search_hit"]`（唯一消费者随之改写，见上表；已核无遍历依赖）。

2. **`highlight_plain_text(text, keyword, surface="light")`**（新增可选参数，默认值保持浅底路径行为；不改函数契约的调用方式）：
   - `light`：`background-color: <bg>; text-decoration: underline;` —— **不再强制文字色**（保留气泡原色，这是「生硬」的主因之一）；
   - `dark`：`background-color: <bg>; color: <fg>; text-decoration: underline;` —— 深底需要提亮文字才有对比；
   - 未知 surface 值 → 回退 `light`（不抛异常）。
   - 调用点：`:1357` / `:1397` 传 `surface="dark"`；`:2475` 保持默认。
3. **兼容性口径（rgba 在 Qt 富文本）**：首选 `rgba(r,g,b,a)`（语义无歧义）。执行时先跑**离屏渲染探针**验证半透明确实生效（渲染 → 取 span 内像素 → 与「纯文字色」对照，若被忽略/渲染为不透明立即发现）；若不生效，退化为**按底预乘出的不透明色**并在 SPEC 附录记录实测结论。
