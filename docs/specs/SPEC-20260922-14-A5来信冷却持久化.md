# A5 收口：来信冷却写回的持久化时机对齐

## 目标

把「主动来信冷却」的写回**立即持久化**，与「日更问候/纪念卡」路径一致，消除「启动即来信 → 进程被杀 → 冷却丢失 → 同日重复来信」的窗口。

## 事实（只读侦察确认）

- `shared/letter_manager.py:191-192`：`state.last_letter_ts = now_ts` / `state.last_letter_date = today_str`，注释明写**「调用方负责持久化 world」**；
- 调用方 `gui.py:_maybe_dispatch_letter`（`:1824-1854`）**没有**任何持久化调用；
- 既有对照：日更问候/纪念卡路径在展示后**立即**持久化（`_save_state`）；`_save_state` 已包含 `"world_state": self.world.save_dict()`（单源 ✓）。

## 非目标

改冷却语义/时长（`MIN_COOLDOWN_HOURS`）；改来信模板/发件人逻辑；改 `letter_manager` 内部结构；顺带改其它持久化时机（A5 之外的时机不动）。
