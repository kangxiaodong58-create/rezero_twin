# SPEC-20260922-29：顶栏去嵌套框 + 去两处 app 图标（L1）

- **SPEC-ID**：SPEC-20260922-29
- **级别**：L1（样式收口 + 两处控件删除；接口/数据零变化）
- **来源**：用户 2026-10-10 三条直接要求（顶栏左图标删除 / 底部图片删除 / 顶栏嵌套框去掉统一主题）
- **等待批准**：**是**

## §1 根因（实测取证，非猜测）

**"一个长框里嵌套一个又一个框" = QSS 裸声明级联到子控件。**

| 容器 | objectName | 当前 QSS | 后果 |
|---|---|---|---|
| `header`（顶栏） | ❌ 无 | `header_shell()` = `background-color:…; border: 1px solid…; border-radius: 18px;`（**无选择器**） | 规则级联到**每个子控件**（图标/标题/双子模式/氛围行/搜索框/按钮）⇒ 各长出一个 1px 框 + 圆角 |
| `dock`（底坞） | ❌ 无 | `dock()`（无选择器） | 同上（4 个入口图标各带一框） |
| `footer`（状态栏） | ❌ 无 | `footer()`（无选择器） | 同上 |
| `input_frame`（输入区） | ❌ 无 | `input_frame()`（无选择器） | 输入区内部各行各带一框 |
| `nav`（左导航） | ✅ `side_nav` | `QFrame#side_nav {…}`（**有选择器**） | 子控件干净 —— **对照组，证明"有选择器就不级联"** |

实测扫描：`ui/theme.py` 共 **19 个无选择器裸声明函数**（清单见执行记录），其中落到上述容器的 4 个是本次主因。

## §2 目标

- **G1 顶栏去嵌套框**：给 `header` 设 `objectName("app_header")` 并把 `header_shell()` 改成 `QFrame#app_header {…}` 作用域；子控件不再继承框。同理处理 `dock`（`app_dock`）/`footer`（`app_footer`）/`input_frame`（`input_frame`），全部 QSS 加选择器。
- **G2 双子模式 chip 去框**：`twin_mode_chip()` 从「有底色 + 有描边 + 圆角」改为**纯文字 + 强调色**（与氛围行同一语言），顶栏只剩一条长条 + 若干无框字段。
- **G3 删除顶栏左侧 app 图标**（`title_mark`，`shell_setup.py` 装配处 3 行）。
- **G4 删除左导航底部 app 图标**（`nav_twins`，含 `theme.nav_twins_slot()` 一处调用；函数保留不删以免动作面扩大）。
  - ⚠️ **待用户确认口径**：用户原话「LLM人生账本14条下面那个图片」——按布局排查，底部区域只有这一张 app 图（`app_icon.png` 140×140）；若指的是别处，请回一句具体位置。
- **G5 结构守卫（防回弹）**：新增用例——**设置了 `setStyleSheet` 的容器控件必须有 objectName 且 QSS 带选择器**（扫 `ui/mixins/shell_setup.py` + `ui/theme.py` 的对应函数对，白名单例外显式登记）。
