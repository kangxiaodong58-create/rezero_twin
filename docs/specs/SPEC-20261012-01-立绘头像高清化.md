# SPEC-20261012-01 立绘与头像高清化（夜色宅邸）

- **SPEC-ID**：SPEC-20261012-01
- **级别**：L1（纯资产替换，不改接口/数据/代码；观感类，**真机门禁=是**）
- **日期**：2026-10-12

## 目标

用 AI 生成的电影级高清资产，替换 Dashboard 双子立绘与聊天头像这两个当前最突出的视觉短板，使角色与「深夜宅邸」深色主题融为一体，消除浅色/亮户外背景在深色界面里的割裂感。

## 背景（实地核查结论）

1. Dashboard 两张角色卡用的是 `{role}_sprite.jpg`（与 `_standing.jpg` 同图）：
   - `ram_sprite.jpg`：**浅灰纯色背景**，深色卡片上像贴了一块浅色明信片；
   - `rem_sprite.jpg`：**明亮户外照片背景**（绿树/蓝天/石板路），与夜色 UI 冲突最严重。
   - 二者均为不透明 JPG，`sprite_card_pixmap` 仅对底部 32% 渐隐，顶部/两侧背景直接暴露。
2. 聊天头像 `rem_face.png` / `ram_face.png`（256²）带浅米色背景，在深色聊天区呈现一圈偏亮的圆。

## 非目标

- 不改任何 `.py` 源码、不改 QSS / design token、不改任何接口或数据结构。
- 不替换全局背景 `mansion_backdrop.svg`、用户头像 `user_avatar.svg`、`{role}_avatar.png`（这些杠杆低/为兜底图，留作后续可选）。
- 不改动角色色身份（蕾姆蓝 `#7FB3D5` / 拉姆粉 `#E8A0BF`），不改变角色人设（女仆装、发饰、遮左眼刘海、花冠均与原作一致）。
- 不做任何布局/导航/交互调整。

## 接口/数据是否变化

- **否**。文件名、扩展名、加载入口（`sprite_card_pixmap` / `AvatarLabel`）完全不变。
- 脸图由 256² 提升到 512²：现有测试不断言脸图像素尺寸（仅断言 `avatar_size=64` 与文件名后缀），且 Qt 按显示尺寸缩放，属安全增强。
- 立绘 JPG 全不透明 → `_first_opaque_row` 第 0 行命中 → 取框上缘 y=0，与现状口径一致，已在预览中验证。
