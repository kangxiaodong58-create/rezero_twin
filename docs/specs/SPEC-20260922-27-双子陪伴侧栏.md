## §2 目标

- **R1 折叠**：标题栏加折叠按钮；折叠后右栏收成 **44px 竖条**（只留展开按钮 + 两个角色名首字竖排），聊天区**自动扩展**；折叠状态**手动优先**，窗口逻辑宽 < **1220** 时自动收起、≥ **1260** 恢复（40px 滞回）。**阈值来自实测（F27-1 闭环）**，见下方曲线表。
- **R2 标题**：`双子 · 陪伴状态` + 折叠按钮（`theme.dash_title_row()`）。
- **R3 卡片层级**：`立绘（240×200 统一取景）` → `名字 + 当前状态（emoji+中文，字号加大一档）` → `一句描述（来自 world.character_actions）` → `关系阶段 + 好感细条（弱化）`；**删除「忠诚锁定」整行** ⇒ 锁定改为**名字后缀小图标**（`🔒`，仅锁定时出现）。
- **R4 视觉减法**：**去掉立绘独立边框**（立绘直接嵌卡片，圆角只由卡片提供）；dashboard 外壳去描边（只留底色）；`RADIUS` 只在卡片层出现一次。
- **R5 强调色柔化**：`rem_accent #56CCF2 → #7FB3D5`、`ram_accent #FF7EB3 → #E8A0BF`（采纳任务书色板；**全局影响列表**见 §风险 R1）。
- **R6 交互态**：卡片 `:hover` 轻微提亮（统一走 theme 函数）；speaking 高亮沿用（轻量描边，不动效开关外的新动画）。
- **R7 立绘取景统一**：`sprite_card_pixmap` 改为**按头部锚定**（先用 `QImage` 找顶部非透明行 → 以头为基准取框），保证两张卡 「头顶到胸口」比例一致。

### §7.4 F27-4 头部锚定取景实现细节（建议采纳）

- alpha 阈值：`alpha < 10` 视为透明；逐行扫描 `y=0..H/3` 找首个含非透明像素的行作为**头顶**；
- 取框：`y0 = max(0, top - 头部留白 8px)`；高度取 `min(H_avail, y0 + H_frame)`；
- **失败回退**：扫不到非透明行（全透明/全不透明）⇒ 回退现有「偏上 1/3」策略；
- 边界用例：全透明图（空 pixmap）、全不透明图（不裁）进 `test_dashboard_assets.py`。

### §7.5 F27-5 折叠条风格来源（建议采纳）

`theme.dash_folded_strip()` 复用 SPEC-26 体系：底 `SURFACE_TINT['detail']` + 边 `COLORS['border_subtle']` + 圆角 `RADIUS['medium']`；文字 `text_secondary`；不做玻璃模糊。

## §9 风险

| 风险 | 缓解 |
|---|---|
| R1 **强调色联动面**（实测：`rem_accent`/`ram_accent` 引用仅 9 处 / 4 文件——`design_tokens` · `dashboard` · `shell_setup` · `test_ui_offscreen`；但**气泡/名字/标签用的是手写同色令牌**：rem `86,204,242` 5 处、ram `255,126,179` 4 处） | 柔化 accent 时**成组核对**同色令牌（否则气泡蓝与强调蓝会分叉）；基线三步法给证据 |
