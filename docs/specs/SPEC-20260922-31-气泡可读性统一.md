# SPEC-20260922-31：气泡可读性与样式统一（L1）

- **SPEC-ID**：SPEC-20260922-31
- **级别**：L1（令牌取值 + 单一表结构；接口/数据零变化）
- **来源**：用户 2026-10-10 两条直接要求（气泡文字提亮 / 双子气泡彩边与用户气泡统一）
- **等待批准**：**是**

## §1 根因（实测）

### ① 气泡正文「深字压深底」= SPEC-26 的**未跟进项**
`design_tokens.ROLE_BUBBLE_STYLES[*]["fg"]` 三处写死 **`#34374d`**（注释原文：*"浅色聊天舞台上的正文"*）。
SPEC-26 D1 把聊天面从近白改为深玻璃（合成 ≈ `#15182a`）后，**该前景色未同步** ⇒

| 角色 | 合成气泡底（10–16% 角色色叠深玻璃） | 现 fg `#34374d` 对比度 | WCAG AA 正文线 |
|---|---|---|---|
| rem | `#20283b` | **1.26 : 1** ❌ | 4.5 : 1 |
| ram | `#2a2639` | **1.25 : 1** ❌ | 4.5 : 1 |
| user | `#21244a` | **1.27 : 1** ❌ | 4.5 : 1 |

### ② 左右气泡有「彩边突出」，用户气泡没有
`rem/ram` = `border-left: 3px solid rgba(角色色,0.45)`（highlight 变体 5px）；`user` = `border: 1px solid rgba(99,102,241,0.30)`（无左突出）。

## §2 目标

- **G1 提亮**：rem/ram/user 的 `fg` → `COLORS['text_primary']`（`#E2E8F0`，合成底上 **≈12 : 1** ✅）；
  streaming 变体 `stream_fg` 保持 `text_secondary`（`#A9B6CE`，≈8.6 : 1，弱化语义不变）。
- **G2 统一**（口径：**用户气泡即范式**）：rem/ram 去掉左彩条，改为与用户气泡**同一句式**的 `border: 1px solid rgba(99,102,241,0.30)`：
  - `border`：`border-left: 3px solid …` → `border: 1px solid COLORS['user_border']`；
  - `hl_border`：`border-left: 5px solid …` → 同 1px 全描边（强调由 `hl_bg` 0.15 底色承担）；
  - `stream_border`：`border-left: 2px solid …` → `border: 1px solid COLORS['border_subtle']`（更弱一档）；
  - **角色色身份不变**：名字标签（`bubble_tag_role` 角色色）+ 底色（0.10 角色色）保留。
- **G3 守卫**：新增用例断言「气泡正文前景 = `text_primary`」+「三角色气泡 **无 `border-left`**」，防回弹。

## §9 风险

| 风险 | 缓解 |
|---|---|
| R1 提亮后气泡文字抢眼过头（与名字标签层级打架） | `#E2E8F0` 与标签色（角色色）色相不同、明度可比 → 真机看；不合适退档 `#DCE3EE`（≈11.4:1） |
| R2 统一描边为紫色细线后，双子气泡"辨识度下降" | 辨识由名字标签 + 底色承担；真机确认；若不认可可改「各自色相 1px」（一档开关） |
| R3 streaming 弱变体在 0.04 底色上过暗 | 实测 `text_secondary` ≈8.6:1，仍在 AA 之上 |
