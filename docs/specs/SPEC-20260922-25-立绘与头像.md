## §F25-6 B3 源图分辨率与提升上限（修订）

- **现有源图实测**：`rem_avatar.png` **512×512** · `ram_avatar.png` **512×512**（不是低清源）。
- **当前为什么"不清晰"**：不是源图分辨率不够，而是「**整图缩到 42px**」——512² 整图是头肩上身构图，脸部只占约 1/3 ⇒ 42px 下**脸部实际仅约 14–17px**。
- **B3 提升上限（诚实口径）**：从 512² 源紧裁，脸部可拿到约 **220–260 像素见方**的真实像素 ⇒ 显示 56/64px 时为 **3.5–4.5× 下采样**，上限足够；**若脸部在原图中不足 220px，则裁切只能"放大构图"、不能"增加细节"**（实施时先量脸部包围盒，实测值写进执行记录）。
- **用户头像 B4**：`user_avatar.svg` 仅 260 B 几何剪影（矢量、无细节可提升）⇒ 只能**替换**，不能"裁切变清晰"。
