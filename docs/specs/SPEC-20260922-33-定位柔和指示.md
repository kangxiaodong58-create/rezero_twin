# SPEC-20260922-33：定位指示做回「柔和档」（L1）

- **SPEC-ID**：SPEC-20260922-33
- **级别**：L1（令牌取值 + 单函数返回；接口/数据零变化）
- **来源**：用户 2026-10-10 真机反馈 —— 「怎么历史记录定位没有相关聊天记录的视觉聚焦了…**主要不是不需要视觉聚焦，只是不要太突兀**」
- **等待批准**：用户直接反馈即指令；真机复核为最终验收

## §1 背景（两次反馈的合成口径）
| 轮次 | 用户反馈 | 处置 | 结果 |
|---|---|---|---|
| SPEC-23 | （原设计）定位闪光 | α=0.55 整块琥珀 | 用户：**太突兀** ✗ |
| SPEC-32 | 「异常出现边框发亮…可以不用进行视觉突出」 | 全关（返回空串） | 用户：**完全没指示了也不行** ✗ |
| **SPEC-33（本版）** | 「不是不需要视觉聚焦，只是不要太突兀」 | **柔和档**：α=0.16 + 1px 同宽描边 | 待真机 |

## §2 目标
- **G1**：`COLORS['locate_highlight']` 0.55 → **0.16**；新增 `COLORS['locate_border'] = rgba(255,205,96,0.38)`；
- **G2**：`theme.locate_highlight()` 恢复返回样式（`background-color` + `border: 1px solid`）——
  描边宽度 **1px 与 `bubble_body()` 的角色描边同宽** ⇒ 施加/移除**不改变气泡尺寸**（无布局抖动）；
- **G3**：**亮度上限机器锁定**：用例断言 α ≤ 0.20 + 定档 0.16（防止将来又回到 0.55 那种突兀档）；
- **G4**：句级柔和高亮（SPEC-20）、滚动定位、2400ms 自动恢复 全部不变。

## §3 非目标
不动输入框（SPEC-32 的"聚焦不换样式"保持不变）；不动气泡常规样式；不引动画/渐变（Qt QSS 无过渡，硬切与旧版一致）。

- @ui/theme.py（`locate_highlight()` 返回柔和样式）
- @tests/test_ui_offscreen.py（`test_locate_flash_disabled` → `test_locate_highlight_is_soft`；SPEC-23 定位用例改回"有柔和闪光"契约）

无。§6 接口/数据：零变化。
