## 二、工作流（每阶段任务书）

1. **Step 1 只读**：只读调查挂载点/现状/边界 → 输出挂载点表 + 最小方案 → **停下等确认**
2. **Step 2 最小方案**：参数表（触发/结束条件、时长/数值、风险回滚、验收用例）→ **停下等确认**
3. **Step 3 实现**：改代码 → 冒烟 + 离屏验证 → CHANGELOG + devlog → 汇报

任务书硬约束典型项：不碰状态机数值、不碰 `parse_twin_segments`/`_streaming_segments`、不碰 Validator/场景冷却、不引入新 UI 框架、动效可关且失败不崩、流式高频路径无动画卡顿。

## 四、铁律

- **数据安全 > 功能**：`.env`、`data/`、`dist/data/` 绝不删除/覆盖；build.ps1 的备份机制勿绕过
- **View-Only**：引言/问候/续聊卡/轻氛围一律 `save=False`，不进 ConversationStore、不进 LLM history
- **snapshot 只读**：读状态用 `engine.snapshot()`；`update("")` 会推进状态机，禁止用于只读
- **commit 纪律**：排除 `data/gui.log`（已跟踪运行日志）；`.env`/`data/`/`dist/` 由 .gitignore 挡；补提交模式，一批版本一个 commit
- **观感类改动**：真机观感确认前不 commit
- **开关先例**：功能级环境变量 `REZERO_DISABLE_XXX=1`（VIGNETTE/HISTORY/UI_MOTION）

## 五、历史坑速查

| 坑 | 版本 | 教训 |
|---|---|---|
| openai/pydantic_core 打包缺失 | V10.0.2 | spec `collect_all('openai')`；构建 venv 与运行时同一 |
| openai 模块级 import 阻断一切 | V10.0.1 | 懒加载进 `__init__` |
| 天气 `hash()` 带进程盐 | V10.4 | 确定性必须 hashlib，且重启验证 |
| LLMWorker finished 条件发射 | V10.2.2 | finished 无条件发射 |
| 跨线程信号直连崩溃 | V10.2.1 | 必须 `Qt.QueuedConnection` |
| 流式双人灌一泡 | V11.11 | 临时泡模式 + 流式分段 |
| insertWidget 后 count-2 取到自己 | V12.1 | 布局「上一条」必须在插入前取 |
| QGraphicsOpacityEffect 残留 | V12.0 | 动画结束 `setGraphicsEffect(None)` |
| 线程泄漏/重入 | V10.2+ | quit/wait/terminate + 断旧信号 + `_streaming_active` 双路径解锁 |
