# 体验优化报告（2026-08-19）：G-1 事件注入强化 + O-1 场景联动

## 一、G-1 事件注入强化（长会话事件被稀释修复）

**背景**：Trial #4-B2 发现——手动设事件后问「今天宅邸有什么新鲜事？」，LLM 回复对话上下文而非事件（事件注入被历史稀释）。

**修复**：`PromptBuilder._build_event_highlight_section(world)`——事件从世界状态普通行提升为**独立高亮小节**：
```
### 今日宅邸事件（用户可能询问，请优先自然回应）
- 事件：一只野猫从庭院围墙跳了进来，正晒着太阳
- 蕾姆对此的倾向：蕾姆会想给野猫留一点食物，又怕惊到它。
- 拉姆对此的倾向：拉姆会说野猫不懂规矩，却不会真的赶它走。
- 双子应对当前事件有自然的反应，而非当作背景板忽略。
```
位置：世界状态节之后、长期记忆节之前（视觉前置）。

**验证**：真机——设红茶事件后问「今天宅邸有什么新鲜事？」，蕾姆主动回应「今天傍晚蕾姆煮了一壶红茶，茶香还留在走廊里」——**事件从背景板变被呼应的对象** ✅

## 二、O-1 场景联动事件（场景×事件一致性）

**背景**：验收观察 O-1——切到书库后若事件是「走廊红茶」，场景与事件地点错位。

**修复**：bridge `_build_messages` 场景切换分支——切换时若事件地点（`_derive_location`）与新场景中文名冲突，则 `world.refresh_active_event()` 刷新事件；地点一致不刷新（稳定性）。

**验证**（测试 3 项）：
- 走廊事件 + 切书库 → 事件刷新（不再走廊）✅
- 书库事件 + 切书库 → 不刷新（地点一致）✅
- 事件高亮节注入含双子倾向 ✅
