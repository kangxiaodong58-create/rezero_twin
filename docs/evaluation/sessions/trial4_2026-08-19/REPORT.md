## 三、优化（已完成 O-4）

### O-4 场景互动文案去重（已完成）
- 原实现 `random.choice`——长会话同一场景互动文案可能随机重复
- 改为**轮转游标 + 避开上次命中**（复用 V14.5 去重思路）；移除无用 random import
- 测试 +1（相邻不重复断言）；127/127 全绿
- **注**：厨房上午 slot 仅 2 条 interaction——轮转在 2 条间交替是池子小的正常表现，扩池可缓解（文案组）

### G-1 观察（未改，建议后续）
- 事件注入在长会话中可能被稀释——可考虑：事件在 prompt 中加粗/前置，或场景切换时刷新事件（O-1）
