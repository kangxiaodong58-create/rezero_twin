## S/A/B/C 台账

### S-01【S 级】本地模板模式：新用户（好感 <50）蕾姆全部常规对话复读「蕾姆会陪着您。」

- **【问题】** 本地模板模式下，好感 0-49（STRANGER/FAMILIAR 档）用户输入任意常规对话（问候/问名字/问天气/闲聊/无意义输入），蕾姆永远返回同一句「蕾姆会陪着您。」；全部 23 个意图桶（3 arc × accompany/tired/sad/from_zero/push/oni_*/aftermath/inferiority）**均无 STRANGER/FAMILIAR 档文案**，`ResponseLibrary.get()` 降级失败落入 fallback。
- **【用户感受】** "这个角色是复读机吗？我问什么它都只会说这一句。刚建立的好感瞬间没了，这软件是不是坏了？"
- **【影响】** S 级——**阻止新用户继续使用**。新用户必经的 0-49 好感阶段（≈前 20-30 轮对话）在本地模式下角色完全无灵魂；README 宣称「本地模式可玩」但实际是复读机。LLM 模式不受影响（生成式），但「零 API 可玩」卖点被击穿。
- **【复现方式】** 隔离数据目录 + `local.ReZeroTwinSystem().interact()`：依次输入「你好」「你是谁？」「你叫什么名字？」「今天天气怎么样？」→ 返回全部为「【蕾姆】: "蕾姆会陪着您。"」。脚本：`docs/evaluation/sessions/trial1_2026-08-19/probe_cli_blind.py`（13 轮，12 轮同句）。量化验证：`probe_favor_impact.py`——favor 0/15/30 均返回 fallback，60 起才正常。
- **【修改建议】**
  1. 内容层（主修）：为全部 23 个桶补齐 STRANGER/FAMILIAR 两档文案（新用户档应体现「礼貌疏离的陌生感」→「渐熟的亲切感」，与 LLM 模式 Prompt 注入的语感一致）。宅邸篇至少补 accompany/tired/sad/from_zero/inferiority 5 桶 × 2 档 = 10 条起步；帝国篇补 8 桶 × 2 档；后期篇补 5 桶 × 2 档。
  2. 逻辑层（兜底，必做）：`ResponseLibrary.get()`（prompts.py L327-336）降级逻辑改为「若无更低档，返回该桶最低档而非 fallback」——保证任何未来新桶不再复读 fallback。
  3. 测试层：`test_favor_growth.py` 补断言——STRANGER 档输入 5 种不同常规输入，返回不得相同；禁止 fallback 文案进入正常回复通道。
- **【预计提升】** 新用户本地模式回复多样性 1 → 10+；首启体验满意度预计 +2 分（满分 10）；「零 API 可玩」卖点恢复成立。

### S-02【S 级】FROM_ZERO 核心剧情触发条件过严——标准升温句被误判 NORMAL

- **【问题】** `_classify_intent`（state.py L638）要求「从零开始」+ 「吧/吧！/吧。/啊」字尾才触发 FROM_ZERO；而 `test_cases.md` Phase 1 标准句「从零开始……如果可以的话，我想和你一起。」以「一起。」结尾 → 判 NORMAL → 3 点 FROM_ZERO 好感奖励丢失（L725）+ 回复进 accompany 桶（叠加 S-01 复读）。**官方测试案例库里的句子都无法触发自己的核心剧情。**
- **【用户感受】** "我说了『从零开始』——那可是蕾姆的台词啊！她怎么毫无反应，还继续复读那句？"
- **【影响】** S 级——「从零开始」是项目灵魂剧情（README 核心卖点、Phase 1 升温高潮），触发条件与案例库脱节；同时 20 轮升温序列好感停滞（25 卡死）部分源于此：praise/温情词漏判导致正向通道几乎只走 +1 陪伴。
- **【复现方式】** 隔离存档 + `HardStateEngine._classify_intent('从零开始……如果可以的话，我想和你一起。')` → 返回 NORMAL（应为 FROM_ZERO）。20 轮连续模拟（probe_phase2_continuous.py）：favor 16→27，第 8-19 轮 12 轮完全卡在 25。
- **【修改建议】**
  1. 放宽条件：`"从零开始" in text` 即可（去掉「吧/啊」字尾要求）；或用语义更强的子串「从零开始」+ 排除否定（「不要说从零开始」）。
  2. 把 `test_cases.md` Phase 1 升温序列 7 句加入 `tests/test_favor_growth.py` 回归断言：每句必须触发预期 intent 且 favor 递增。
- **【预计提升】** 核心剧情可触发；升温序列好感曲线恢复（预期 20 轮 favor 25 → 50+ 达标 CLOSE）；S-01 复读叠加面缩小。

### A-01【A 级】边界试探词库不完整——「滚开」不触发 BOUNDARY_TEST、不扣分

- **【问题】** `_classify_intent`（state.py L642）BOUNDARY_TEST 关键词仅 ["黑化","侮辱","低俗","下跪","舔狗","恶搞"]；日常攻击词「滚开」「闭嘴」「走开」「讨厌你」等全部漏检 → 「滚开」因 len<10 判 QUICK → 不触发 -3 轻度冒犯扣分（L685-687），蕾姆照常温柔陪伴。**用户骂人零代价。**
- **【用户感受】** "我骂她滚开，她还在说『蕾姆会陪着您』——这角色没有自尊的吗？"
- **【影响】** A 级——边界测试（test_cases.md Phase 4 核心）在真实攻击下失效；好感惩罚机制形同虚设，关系结构（尊重→信任）失去压力面。
- **【复现方式】** `_classify_intent('滚开')` → QUICK（应为 BOUNDARY_TEST）；`_classify_intent('你只是拉姆的替代品')` → MENTION_RAM（替代品贬低通道仍触发扣分，但主冒犯词漏检）。
- **【修改建议】** BOUNDARY_TEST 关键词扩池：["滚","闭嘴","走开","讨厌","废物","没用","打你","杀"]（注意「滚」需排除「滚烫/滚动」正词——用子串白名单或 len≥2 词）；补测试：Phase 4 攻击句全序列断言扣分。
- **【预计提升】** 攻击性输入触发边界回复 + 扣分；角色自尊感恢复，关系成长有真实压力面。

### B-01【B 级】离屏/无 API 环境下引言生成崩溃（0xC0000409 原生崩溃）

- **【问题】** 无 `REZERO_DISABLE_VIGNETTE=1` 时，离屏启动 GUI 在事件循环内原生崩溃（Qt 0xC0000409），无 Python traceback；加环境变量后稳定。GUI 真机（有显示器 + 有 key）不受影响。
- **【用户感受】** 正常用户真机不遇到；但 CI/测试/无头环境跑 GUI 会崩。
- **【影响】** B 级——测试基础设施稳定性；不影响真机用户。
- **【复现方式】** `QT_QPA_PLATFORM=offscreen python gui.py`（隔离 data 目录，不设 REZERO_DISABLE_VIGNETTE）→ 事件循环崩溃。
- **【修改建议】** VignetteWorker（引言 LLM 调用）增加离屏/无 key 检测：`QT_QPA_PLATFORM==offscreen` 或 API key 缺失时走 L2/L3 模板路径（与 frozen 一致），不建 QThread。
- **【预计提升】** 离屏测试稳定，GUI 冒烟可自动化。

### B-02【B 级】输入框与搜索框无视觉区分（小白首启可能混淆）

## Trial #2 补充问题（2026-08-19，LLM 真机深度测试）

### E-01【A 级，已修复】validator 对拉姆误禁第一人称 → 对话异常回退兜底

- **【问题】** `_has_first_person` 对【蕾姆】【拉姆】统一检查「我」；但 prompt 第三人称约束只属于蕾姆，拉姆傲娇人设合法用「我/我可」。32 轮长会话中 2 轮（6%）被拦 → 用户看到「……这个话题，蕾姆想先放一放」的兜底（角色拒绝回答的怪异感）。
- **【修复】** validators.py：仅检查【蕾姆】行；测试 +3（拉姆放行×2、蕾姆仍拦）。提交 `e7073b4`。
- **【预计提升】** 拉姆正常对话不再误回退；6% 异常率归零。

### E-02【A 级，已修复】口语化自我介绍漏提取名字 → 跨天全用「客人大人」

- **【问题】** `_extract_name` 只认「我叫/称呼我/我的名字是」；真实用户说「你好，我是小东」「请叫我小刚」不匹配 → 名字永远记不住（跨天记忆验证暴露）。
- **【修复】** state.py：补「我是X/请叫我X」模式 + 排除角色自称（我是蕾姆/拉姆/女仆/客人）；测试 +8。提交 `5f5cece`。
- **【预计提升】** 常见自我介绍路径名字提取率提升；跨天称呼一致性修复。

### E-03【C 级，观察】长上下文后 validator 边界误拦

- **【问题】** Day4 跨天回归「你还记得我是谁吗？」被拦回退兜底——长上下文累积后 validator 某规则误判（原因未定位到具体词，低概率）。
