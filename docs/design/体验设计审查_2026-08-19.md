## 二、段落排版 / 分段断点（气泡渲染）

### 现状
- 气泡正文 12px（V14.5 11→12）、`line-height: 150%`（RichText，V14.5 修复 AutoText 不生效）
- `setWordWrap(True)`——换行交 Qt 引擎（CJK 行首禁则依赖 Qt 内置 kinsoku）
- 气泡内 padding 12px 16px、圆角 RADIUS.large
- LLM 回复多段：LLMWorker 按【蕾姆】/【拉姆】标签拆气泡（parse_twin_segments）

### 诊断
| 项 | 现状 | 评级 |
|---|---|---|
| 字号 | 12px（中文可读基线） | ✅ |
| 行距 | 1.5 倍 | ✅ |
| 分段 | 按角色标签拆泡（每角色一个气泡） | ✅ |
| **段内多句** | 同角色多句挤一个气泡，**无句间空行** | 🟡 长回复阅读疲劳 |
| **标点悬挂** | 无显式处理（Qt kinsoku 部分覆盖） | 🟡 低影响 |
| **气泡最大宽** | 无固定上限（随窗口） | 🟡 超宽屏整行过长 |

**优化候选（开发侧，非文案）**：
1. 同角色多段回复在气泡内加「段间空行」（LLM 输出含换行时）
2. 气泡最大宽度上限（如 720px）避免超宽屏整行过长
3. 时间戳/角色名层级已有（caption 8px）——已够

## 四、好感/独立度增长曲线机制

### 现状（state.py）
```
好感阈值：STRANGER 0 / FAMILIAR 20 / CLOSE 50 / DEAR 80 / BELOVED 95
增长通道：
  表扬 +2（PRAISE 词）     独立度 +0.01
  温情 +1（WARM 词）
  陪伴 +1（普通轮，5涨3停防刷）
  从零开始 +3（高光）
  名字告知 +4（首次）
  替代品肯定 → 独立度 +0.06（不涨好感）
扣分通道：高危 -12 / 边界 -3 / 替代品攻击 -1
豁免层：DEAR 小额豁免、BELOVED 大额豁免、锁定保护
```

### 诊断
| 项 | 现状 | 评级 |
|---|---|---|
| 曲线结构 | 5 档 × 多通道，成长有层次 | ✅ |
| 防刷 | 5涨3停 | ✅ |
| 高光节点 | 从零/名字/锁定 | ✅ |
| **曲线可视化** | 无（用户只能看数字） | 🟡 建议状态面板加成长进度条 |
| **独立度 vs 好感解耦** | 独立度走肯定句通道（+0.06），好感走表扬（+2）——两者可异步 | ✅ 设计正确 |
| **拉姆好感** | 提及 +1/表扬叠加 +2，独立于蕾姆 | ✅ |

**优化候选**：状态面板加「好感进度条 + 下一阶段距离」（如 45/50 差 5 到 CLOSE）——提升成长期待感（体验侧，非文案）。

## 五、篇章均衡性审查（⚠️ 重点发现）

### 文案分布（2026-08-19 实测）
| 资产 | 宅邸 mansion | 帝国 empire | 后期 late | 失衡度 |
|---|---|---|---|---|
| registry（引言/来信/归来） | 23 | 33 | 17 | 尚可 |
| **letters（主动来信）** | **40** | **3** | **0** | 🔴 极端失衡 |
| **scene_dialogue（场景互动）** | **7 场景全宅邸** | **0** | **0** | 🔴 无篇章维度 |
| character_dialogue（人物） | 5 人物（通用） | 0 | 0 | 🟡 |
| milestone（名场面） | 5 类（通用） | 部分 | 部分 | 🟡 |

### 诊断
1. **场景互动池 100% 宅邸化**：用户切帝国/后期篇后「去厨房」仍注入宅邸场景文案——**帝国篇场景（营地/旅店/篝火）与后期篇场景（战场/军团驻地）完全缺失**
2. **letters 后期 0 条**：后期篇用户永远收不到主动来信（arc 过滤后无模板→静默）
3. 帝国场景可用「旅店/荒野/营地」适配；后期场景可用「军营/战场边缘/宿营地」

**这是「突出单一篇章影响各篇章体验」的直接证据**——场景互动池扩池必须加 arc 维度（见文案需求文档）。
