## 二、需求：后期篇来信 15 条（arcs:["late_arc"]）

### 2.1 桶分配（覆盖五桶，防某桶静默）

| 桶 | 条数 | 语感基调 |
|---|---|---|
| CROSS_PERIOD（跨时段） | 3 | 战斗间隙的简短问候（战友式） |
| HALF_DAY（半天） | 3 | 短暂离开后的呼应（并肩感） |
| DAYS_1_3（1-3 天） | 3 | 牵挂但不煽情（托付信任） |
| DAYS_3_7（3-7 天） | 3 | 更深的挂念（克制深情+战友） |
| LONG_ABSENCE（7 天+） | 3 | 重逢的等待（坚定托付） |

### 2.2 sender 分配（每桶 rem/ram 混合）

| sender | 建议条数 | 语感 |
|---|---|---|
| rem（蕾姆） | 7 | 并肩托付、克制的深情、「蕾姆会站在您身边」 |
| ram（拉姆） | 5 | 傲娇认可、托付语义、「已经证明自己的人」 |
| twins（双子合写） | 3 | 复合来信（【蕾姆】/【拉姆】双泡） |

### 2.3 语感红线（与帝国/宅邸严格区分）

| 维度 | 后期篇（应） | 禁止 |
|---|---|---|
| 关系 | 战友 + 托付（「并肩」） | 早期「可疑的客人」口吻 |
| 深情 | 克制（「蕾姆会在您身边」式） | 宅邸女仆腔（客人大人/茶点） |
| 拉姆 | 认可 + 责任（「已经证明了自己」） | 无条件讨好 / 恋爱化 |
| 世界观 | 战场/营地/军旅意象 | 现代词 / 其他作品串场 |

### 2.4 占位符（与既有模板一致，自动插值）
- `{last_period}` / `{current_period}`（时段）
- `{days_absent}` / `{hours_absent}`（离线时长）
- `{weather}`（天气）

## 三、交付格式约定

- 纯中文；蕾姆第三人称 / 拉姆傲娇（沿用 V14.6 角色卡语感）
- 每条 text 1-2 句，≤60 字为宜；twins 复合来信用【蕾姆】/【拉姆】前缀
- id 命名：`late_rem_cross_01` / `late_ram_days_01` / `late_twins_long_01`（arc_sender_bucket_序号）
- arcs 固定 `["late_arc"]`
- 分批：先 rem 7 条（优先级高——蕾姆后期语感是核心），再 ram 5 条，再 twins 3 条
