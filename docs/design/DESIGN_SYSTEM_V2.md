## 一、动效四律（MOTION token）

1. **物理缓动**：禁止线性。入场 `OutCubic`，到位回弹 `OutBack`（幅度 ≤1.03，禁止生硬撞击）。
2. **时长纪律**：`fast=150ms`（微反馈）/ `base=220ms`（入场）/ `slow=320ms`（浮层）。低于 100ms 突兀、超 400ms 迟滞——越过即违宪。
3. **级联错落**：同组元素入场 `stagger_ms=30`，**至多前 `stagger_max=8` 项**（其后同时出现）——列表不是瀑布，也不是铁板。
4. **动效为功能服务**：每个动效必须在 CHANGELOG 回答"它引导什么"。回答不了 = 不做。
5. **性能红线**（本项目流血教训）：动画只作用于**完成态**消息（流式 chunk 永远不动画）；同屏并发动画 ≤12；`QT_QPA_PLATFORM=offscreen` 自动禁用（测试确定性）；长会话压测须含动画开启采样。

## 二、字排（TYPE token）

- 行高：正文 **155%**（气泡富文本已落地，V10.9.2 机制）、标题 120%。
- 字阶：新增组件遵循 1.25 模数（从 body=10 推：10/12.5/16/20）；存量字号不动，逐步收敛。
- 大字收紧、英文全大写标签 `letter-spacing` 加宽（`QFont.setLetterSpacing`，QSS 不支持）。
- 暗色补偿：雅黑非可变字体 → 暗色下用**色阶**微调（text_primary 已是 #E2E8F0 而非纯白）。

## 三、层级与光影（ELEVATION token，widgets 代偿策略）

- **1px 内发光顶边**：一切"浮起"表面（卡片/浮层/输入框）顶部 `rgba(255,255,255,0.07)` 受光高光——让元素从背景"立"起来的最低成本配方。
- 边框分档：`card=0.10` / `subtle=0.08` / `focus=0.15`。
- 真多层弥散阴影：QML 时代解锁；widgets 用内发光 + 背景遮罩档位表达层级。

## 四、色彩纪律（继承 V1 + 强化）

- 无纯黑纯白（bg_base=#121319 蓝调深灰已是范本）；所有灰调混 1%~3% 主色相。
- **玻璃五档透明度**（SURFACE token， Different layers, different opacity——同层同档禁止遍地 rgba 乱飞）：遮罩 15 / 快捷件 35 / 侧栏 45 / 主卡 55 / 输入 60。

## 五、验收与检查单（UX 委员会动效/质感十项）

每轮审判逐项过，任何"否"即进台账：
1. 无匀速直线动画？ 2. 时长全部在 100–400ms？ 3. 列表入场有级联且 ≤8 项错落？ 4. 浮层表面有内发光顶边？ 5. 玻璃透明度是否用了分档 token（而非手写 rgba）？ 6. 暗部无纯黑、亮部无纯白？ 7. 正文行高 ≥150%？ 8. 动效是否有明确的"引导什么"答案？ 9. 流式输出期间零动画？ 10. offscreen 下动画全禁用（测试确定性）？
