# Re:Zero 双子系统 —— GUI 使用说明

## 文件位置

- 窗口程序入口：`gui.py`
- 双击运行 EXE：`dist\ReZeroTwin.exe`

## 已实现功能

### 1. 聊天界面

- 窗口标题：`Re:Zero 双子系统`
- 聊天区显示历史消息
- 输入框输入文字，按 **回车发送**
- 按 **Shift + 回车** 可换行

### 2. 角色颜色

| 角色 | 颜色 |
|------|------|
| 你   | 深灰 #2c3e50 |
| 蕾姆 | 粉红 #e91e63 |
| 拉姆 | 紫色 #9c27b0 |
| 系统 | 灰色 #7f8c8d |

### 3. 指令

| 指令 | 说明 |
|------|------|
| `/status` | 查看当前状态（好感度、篇章、独立度等） |
| `/empire` | 切换至帝国篇（失忆） |
| `/mansion` | 切换回宅邸篇 |
| `/late` | 切换至后期篇章 |
| `/recover 0.7` | 设置记忆恢复进度为 0.7 |
| `/quit` 或 `退出` | 关闭窗口 |

### 4. 长期记忆

所有数据保存在项目目录下的：

```
data/memory.json
```

保存内容包括：
- 用户昵称
- 蕾姆好感度
- 拉姆好感度
- 人格独立度
- 记忆恢复进度
- 当前篇章
- 最近 200 条聊天记录

程序关闭后再打开，会自动恢复上述记忆。

## 打包方式

如需重新打包 EXE：

```powershell
cd C:\Users\11985\.qclaw\workspace\rezero_twin
pyinstaller -F -w -n ReZeroTwin gui.py
```

打包完成后，EXE 位于 `dist\ReZeroTwin.exe`。

## 当前模式

GUI 版本当前使用 **本地模板模式**，不调用任何 API，无需网络，无需充值。

如需切换为 LLM 桥接模式（需要 Deepseek API Key 且账户有余额），需修改 `gui.py` 中的 `self.mode` 和相关调用逻辑。
