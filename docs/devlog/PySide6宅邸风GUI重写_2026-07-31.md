# PySide6 宅邸女仆风 GUI 全面重写 — 2026-07-31

## 背景

原 Tkinter GUI 已迁移到 PySide6 初版，但存在 7 个核心 bug：
- chat_history 新旧格式不兼容（`{role,content}` vs `{sender,text}`）
- 双子回复被合并为一个"双子"消息，蕾姆/拉姆个性在 UI 层丢失
- LLM 调用在主线程同步执行导致 UI 冻结
- 7 条内置指令（/status 等）全部丢失
- QSS 样式表对所有 QFrame 一刀切，无层次感
- 文字头像显示中文前两字，效果极差
- 气泡宽度硬编码 520px

### 修复的 7 个 bug

1. ✅ chat_history 兼容旧格式 `{role,content}` → 自动迁移为 `{sender,text}`
2. ✅ 回复解析还原：`【蕾姆】`→蓝色气泡，`【拉姆】`→粉色气泡，`【系统】`→灰色
3. ✅ LLM 调用移入 `QThread`（`LLMWorker`），UI 不再冻结
4. ✅ 全部指令恢复：`/status /empire /mansion /late /recover /llm /local`
5. ✅ QSS 分层：`CharacterPanel`/`header`/`input_frame`/`footer` 独立样式
6. ✅ 头像：立绘缩略图→圆形裁剪，无立绘时 emoji 兜底（🩵💗👤⚙️）
7. ✅ 气泡宽度改为 `setMaximumWidth(520)`，后续可改百分比响应式
