# V10.3 世界状态持久化 + 开场引言 — 2026-07-31

## Phase 1：天气冲突修复

**问题**：每次重启程序，天气重新随机 → 与历史记录矛盾。

**修复**：
- 天气改为**按日期确定性生成**（`_weather_for_date(date_str)`），同一日期始终相同天气
- `WorldState` 新增 `save_dict()` / `load_or_create()` 持久化方法
- GUI 启动时从 `memory.json` 恢复世界状态，退出时自动保存
- 跨天时天气自然过渡到当天确定性值

## Phase 2：Opening Vignette 开场引言

LLM 模式首次启动（无历史对话）时，自动生成文学性场景描写：

> 夜雨细密地落在宅邸的屋檐上。客厅的灯只开了一半，光线偏暖。
> 蕾姆坐在窗边整理餐具，偶尔抬头看被雨水打湿的玻璃。
> 拉姆靠在沙发扶手上，闭着眼却并没有真的睡着……

**实现**：
- `gui.py._generate_vignette()`：异步 LLMWorker 生成，不阻塞 UI
- 显示 "✨ 正在感知宅邸的氛围…" → 收到回复后替换为引言
- 失败时回退到简洁的默认描述
