## 修改内容（仅 gui.py + CHANGELOG）

1. **侧栏说话态描边**：`CharacterPanel.set_speaking()`——流式时当前说话人一侧 `avatar_frame` 描边切换为角色色 2px。幂等：`_current_speaker` 比较后才刷 QSS，每轮流式最多 2–3 次样式重设。
2. **正式泡轻入场**：`_append_parsed_message` 新增 `animate=True`；`QGraphicsOpacityEffect` + `QPropertyAnimation` opacity 0→1（200ms/OutCubic），动画结束卸载 effect（防离屏渲染残留）。历史回放传 `animate=False`；streaming/system/vignette 无入场。
3. **状态栏呼吸**：`_mode_label` 挂常驻 effect，`QSequentialAnimationGroup` 双程往复 0.85↔1.0（单程 2s/InOutSine）；思考中 `pause()` 停在当前值、完成后 `resume()`。
4. **统一开关**：`ENABLE_UI_MOTION` + `REZERO_DISABLE_UI_MOTION=1`（对齐 `REZERO_DISABLE_VIGNETTE` 先例）；所有动效路径 try/except 只记日志。

## 踩坑记录

- **Hermes 会话 PYTHONPATH 污染**：会话注入 `PYTHONPATH=hermes-agent venv`，导致项目 venv 的 `import openai` 加载到错误 pydantic_core 二进制（`ModuleNotFoundError: pydantic_core._pydantic_core`），冒烟假失败。修复：`env -u PYTHONPATH venv/Scripts/python.exe`。已沉淀至 memory + skill。
- **QGraphicsOpacityEffect 必须卸载**：动画结束不 `setGraphicsEffect(None)` 会让每个气泡常驻离屏渲染，批量消息后性能劣化。
