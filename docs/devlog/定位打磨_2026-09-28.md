## 2. 离屏取证（F23-2）：先把「加 α 有没有用」测出来

探针 `probe_bg4.py`（父容器用**作用域选择器**模拟聊天区底 `#DDDCE8`——无选择器的父样式表会级联污染子控件，第一版探针就是这样取错色的）：

| 变体 | 容器内实测像素 | 对比底 Δ |
|---|---|---|
| 无闪光 | (221,220,232) | — |
| 现状 0.15 + 圆角 | (226,219,197) | (+5,−1,−35) |
| 草稿候选 0.28 | (230,216,194) | (+9,−4,−38) ⇒ **与现状只差 3 个色阶** |
| 定稿 0.55 | **(240,212,158)** | **(+19,−8,−74)** |
| 描边 0.65（隔离测） | (247,209,130) | (+26,−11,−102) |

**结论**：15%→28% 是假动作（人眼根本分不出）；可见度必须来自机制升级，不是 α 微调。

## 3. 描边方案实测否决（`probe_bg5.py`）

批准的定稿是「0.55 底色 + 2px 描边」。实测：**QSS `border` 会把气泡原点从 (92,50) 推到 (92,54)（位移 4px）**——
QSS 边框参与内容盒计算，闪光一亮一灭整行内容抖 4px（观感瑕疵），而且会把位移烘进截图基线（污染后续所有对比）。

⇒ 改用**纯底色 α=0.55**：ΔB=−74，达描边方案 (−102) 的 73%，无位移、无硬边（与项目「柔和」口径一致）。
已回写 SPEC §11「实施与批准的偏离」表（含依据）。
