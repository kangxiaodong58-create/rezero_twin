## Phase 1：WorldState 修复与增强（shared/state.py）

### 真 bug：天气确定性从未生效

```python
# 修复前（v10.3）
seed = hash(date_str + "roswaal") % 100   # ← 内置 hash() 对字符串带进程随机盐
```

每次启动新进程，同一日期算出不同天气——正是 v10.3 要修的问题本身。

```python
# 修复后（v10.4）
raw = f"{system_date}_{period}_{seed}".encode("utf-8")
point = int(hashlib.md5(raw).hexdigest()[:8], 16) % sum(WEATHER_WEIGHTS.values())
```

权重保持 v10.3 文档化分布：晴 40 / 多云 25 / 小雨 17 / 大雨 11 / 阴沉 7。

### 死字段激活：days_since_last

此前只从存档读、写回，从不计算。新增 `last_interaction_ts` 字段：
- 启动时 `days_away = (now - last_interaction_ts) // 86400`
- `mark_interaction()` 在用户发送有效对话时刷新（GUI 已接入；/status 等命令不触发）
- 旧存档无该字段时回退到存档的 days_since_last，无缝兼容

### 天气自然推演

≥8 小时未启动：`weather_seed = (seed + hours*10) % 100000`，按新种子确定性重算天气；
8 小时内重启保持存档天气不变。同一 (日期, 时段, 种子) 永远同一天气。

### 新增字段

`weather_seed` / `weather_last_change` / `last_interaction_ts` / `character_actions`
（蕾姆/拉姆当前动作，默认「在整理房间」「靠在一旁休息」）。

## Phase 2：shared/vignette.py（新文件）

### L0-L3 弹力兜底网

| 层 | 实现 | 成本 |
|----|------|------|
| L0 | 会话内存缓存 + `data/vignette_cache.json`（LRU 40 条） | 0 |
| L1 | LLM ≤3 次重试，温度 0.78→0.65 衰减，清洗校验 | 1 次 API |
| L2 | 动态槽位模板（时段/天气/双子动作/氛围 extras） | 0 |
| L3 | 静态兜底文案 | 0 |

缓存 key：`md5(时段|天气|离开天数桶(0/1-2/3+)|蕾姆等级|拉姆阶段)[:12]`

### 校验规则（sanitize_and_validate）

- 剥前缀杂质（"好的"/"以下是"/"```" 等）；括号整包视为 `raw_completion` 错误回包，拒收
- 字数 80~180；违禁词（用户/玩家/系统/AI/主人您好 等）；「您+吗/呢/吧？」直接对话拒收

### 设计裁剪（相对 docx 原案）

1. **不新建独立 world_state.json**：沿用 memory.json 持久化管线，只新增 vignette_cache.json——避免双持久化路径
2. **生成器不持有 OpenAI client**：改收 `llm_callable`（即 `bridge.raw_completion`，签名天然兼容 temperature/max_tokens），保护 v10.0.1 懒加载修复
3. **本地模式行为不变**：非 LLM 模式仍显示原欢迎语，不引入模板引言

### gui.py 接入

`_generate_vignette` 重写为调用 `VignetteGenerator`，保持 QThread 异步、
"✨ 正在感知宅邸的氛围…"占位与 View-Only 铁律（save=False，绝不进 messages）。
