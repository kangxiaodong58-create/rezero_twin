# V10.1 双子独立气泡 + 世界事件系统 — 2026-07-31

## 改动概览

### 1. 修复流式双气泡（bug fix）

**问题**：LLM 流式回复中，【拉姆】和【蕾姆】的台词被塞进同一个气泡。

**根因**：`_on_stream_token` 根据首个 token 判断角色后，所有后续 token
（包括另一个角色的台词）全部灌入同一个 `ChatMessageWidget`。

**修复**：
- `_on_stream_token`：流式进行中使用一个临时 "system" 气泡预览
- `_on_stream_finished`：移除临时气泡 → 调 `_parse_twin_reply()` 拆分
- 拉姆气泡 = 粉色（`#fce4ec`），蕾姆气泡 = 蓝色（`#d6e4f0`）

### 2. 性能优化

| 优化 | 说明 |
|------|------|
| Widget 泄漏 | `MAX_VISIBLE_WIDGETS = 80`，超出自动移除最早的 widget |
| 历史上限 | chat_history 限制 300 条，LLM history 限制 8 轮 |
| LLM 始终流式 | `_send_message` 对 LLM 模式强制走 `chat_stream`，不阻塞 UI |

### 3. 新增 WorldState（世界事件系统）

文件：`shared/state.py` → `WorldState`

```
@dataclass
class WorldState:
    period: str        # 清晨/上午/…/深夜（7段）
    weather: str       # 晴朗/多云/小雨/大雨/阴沉
    days_since_last: int
```

**时间**：`WorldState.now()` 按现实时间自动计算时段。

**天气**：基于小时 hash 的伪随机（同一小时内稳定），5 种天气 + 日夜差异化描写：
- 白天晴朗 → "阳光温暖地洒进宅邸"
- 夜晚晴朗 → "月光透过窗户洒在走廊上"
- 雨天 → "夜雨轻轻敲打着窗棂"

**注入**：`bridge.py._build_messages()` → `PromptBuilder.build(state, world=world)`
→ Prompt 新增`### 当前世界状态`小节

**GUI**：底部状态栏显示 `夜晚 · 晴朗 | 好感 15/100 | 可疑`

### 4. 代码清理

- `llm/bridge.py`：移除冗余 `sys.path` 操作
- `shared/state.py`：WorldState 使用 `@dataclass`，紧凑
