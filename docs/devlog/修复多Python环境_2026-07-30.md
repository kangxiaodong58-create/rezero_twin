# 修复多 Python 环境问题

## 现象

用户在 PowerShell 中手动输入 `python main.py --mode llm` 时报错：

```
ValueError: 未提供 DEEPSEEK_API_KEY。请在 .env 文件中设置或传入环境变量。
```

## 根因

用户电脑上存在多个 Python 解释器：

1. `D:\python\python.exe`（Python 3.14.3）← 手动输入 `python` 时实际调用的
2. `D:\Q-claw\QClaw\v0.2.35.624\resources\python\python.exe` ← OpenClaw 内部使用的

之前安装 `openai` 和 `python-dotenv` 时使用的是 OpenClaw 自带的 Python，而用户启动时用的是 `D:\python\python.exe`，该环境中缺少 `python-dotenv`，导致 `.env` 文件没有被加载。

## 解决方案

在用户实际使用的 Python 环境中安装依赖：

```powershell
D:\python\python.exe -m pip install openai python-dotenv
```

## 后续使用

由于 `python` 默认指向 `D:\python\python.exe`，建议以后都用这个解释器运行：


