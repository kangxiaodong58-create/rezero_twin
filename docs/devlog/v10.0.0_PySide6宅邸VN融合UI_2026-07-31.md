# V10.0.0 PySide6 宅邸×VN 融合 UI + 立绘 + 樱花动画 — 2026-07-31

## 概述

从 Tkinter 完全迁移到 PySide6，重新设计为「宅邸女仆 + Galgame 视觉小说」融合布局。

## 架构变更

### 新增文件
- `assets/rem_sprite.jpg` — 蕾姆立绘（蓝发）
- `assets/ram_sprite.jpg` — 拉姆立绘（粉发）

### 重写文件
- `gui.py` — 完全重写（Tkinter → PySide6），~1100 行

### 修改文件
- `llm/bridge.py` — 新增 `chat_stream()` 流式输出方法

## 详细改动

### 1. gui.py 核心修复（vs 上一版 PySide6 尝试）

| 问题 | 修复 |
|------|------|
| chat_history 格式断裂（旧 `{role, content}` / 新 `{sender, text}`） | `_load_history()` 同时兼容两种格式 |
| 双子回复当成一个"双子"消息 | `_parse_twin_reply()` 按【蕾姆】/【拉姆】分行解析 |
| LLM 调用阻塞主线程 | `LLMWorker(QObject)` + `QThread` 异步 |
| 命令丢失 | 补回 /status /empire /mansion /late /recover /toggle |
| 头像文字丑陋 | `AvatarLabel` emoji 圆形头像 |

### 2. 布局：宅邸 × VN 三栏

```
[蕾姆面板 180px] [聊天区域 flex] [拉姆面板 180px]
├ 立绘 (240px高)    ├ 樱花飘落叠加层     ├ 立绘 (240px高)
├ 好感/阶段/情绪    ├ 气泡对话区          ├ 好感/阶段/情绪
└ 锁定标记         ├ 快捷命令按钮        └ 状态
                   └ 输入框
```

### 3. 角色立绘

- `CharacterPanel` 新增 `sprite_path` 参数
- 加载 `assets/rem_sprite.jpg` 和 `assets/ram_sprite.jpg`
- 图片自动缩放至 160×230（`Qt.KeepAspectRatio + SmoothTransformation`）
- 无图片时 fallback 到 emoji + 虚线框占位

### 4. 樱花飘落动画

- `SakuraOverlay(QWidget)` — 透明叠加层，不拦截鼠标
- 35 个花瓣粒子，5 种粉色
- QTimer 30fps 更新位置+旋转
- 五瓣樱花绘制（5 个椭圆 + 中心圆）
- 跟随 viewport resize 自适应

### 5. 流式输出

- `ReZeroLLMBridge.chat_stream()` — 返回 generator + state
- GUI 通过 `LLMWorker.stream_token` signal 逐 token 更新气泡
- 首个 token 到达时自动判断角色（【蕾姆】→rem / 【拉姆】→ram）

### 6. 主题配色

| 元素 | 颜色 |
|------|------|
| 背景 | #f0ebe3 (米白和纸色) |
| 顶栏 | #3a2f28 (深棕木色) |
| 蕾姆 | #5b9bd5 蓝 / #d6e4f0 气泡蓝 |
| 拉姆 | #e982a5 粉 / #fce4ec 气泡粉 |
| 金色点缀 | #c9a96e |
