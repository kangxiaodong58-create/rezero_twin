# V10.2.2 LLMWorker finished 信号修复 — 2026-07-31

## 根因（一个 bug 引发三个症状）

`LLMWorker.run()` 中：

```python
# 修复前
for token in gen:
    full += token
    self.stream_token.emit(token)
if not full:
    self.finished.emit("")   # ← BUG：只在 full 为空时发射！
```

流式输出有内容时 `finished` 信号从不发射，导致：

| 症状 | 原因链 |
|------|--------|
| 退出重进后只有用户消息，无角色回复 | `_on_stream_finished` 不触发 → `_parse_twin_reply` 不调用 → `conv_store.append` 不执行 |
| 拉姆/蕾姆仍在同一气泡 | 同上，拆分逻辑 `_parse_twin_reply` 从未执行 |
| 第二轮起显示"双子正在回复中"后卡死 | `_streaming_active` 仅在 `_finish_reply()` 中重置，而 `_finish_reply` 由 `_on_stream_finished` 调用 |

## 修复

```python
# 修复后
for token in gen:
    full += token
    self.stream_token.emit(token)
self.finished.emit(full)   # ← 始终发射，无论 full 是否为空
```
