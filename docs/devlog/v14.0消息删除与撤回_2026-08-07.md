## 修改内容

### `shared/conversation_store.py`（schema + 3 处查询过滤 + 1 新方法）

1. **`messages.status` 列**（normal/recalled/deleted/failed）：新库建表含列；旧库 PRAGMA 检查 + `ALTER TABLE` 幂等迁移（存量行默认 normal）。
2. **`update_status(message_id, status)`**：软状态更新（非法 status 拒绝，返回是否命中）。
3. **过滤差**（代码注释已写明，三条路径）：
   - `get_recent` / `get_messages_since`：`status IN ('normal','failed','recalled')`（GUI 展示：deleted 隐藏，failed/recalled 可见）
   - `search`：FTS 通道 `AND m.status='normal'`、LIKE 通道 `AND status='normal'`（非 normal 正文不可搜）
   - `get_by_id` 返回 status（撤回窗口判断用）

### `llm/bridge.py`（1 处）

- `_restore_history_from_store`：`status != 'normal'` 行跳过——failed/recalled/deleted 均不进 LLM 上下文（V14.0 删除/撤回后剪枝的落点）。

### `gui.py`（widget 层 + 主窗口）

1. **ChatMessageWidget**：`recall_requested`/`delete_requested` 信号；`_status`；`set_recalled()`（占位文本 + 45% 透明度）；`set_failed()`（名字后缀「（未送达）」+ 55% 透明度）；`contextMenuEvent`（撤回仅 user 且 normal；删除任意有 id）。
2. **SystemLabelWidget**：`message_id` 参数 + `delete_requested` 信号 + 右键删除（瞬态标签无 id 无菜单）。
3. **`_append_parsed_message`**：system 分支透传 message_id + 信号接线。
4. **`_send_message`**：记录 `_pending_user_widget`（本轮用户句）。
5. **`_cancel_streaming`**：pending → `update_status(failed)` + `set_failed()`（V14.0 失败态）。
6. **`_finish_reply`**：成功路径清 pending。
7. **`_load_history`**：按 status 渲染（recalled 占位 / failed 标记）。
8. **主窗口 handlers**：`_on_recall_request`（user+normal+3 分钟窗口+确认框）/ `_on_delete_request`（确认框）/ `_prune_bridge_history`（restore 重建）/ `_mark_widget_recalled` / `_remove_widget_by_id`。

## 行为变化声明

- 撤回：仅用户自己的消息、created_at 起 3 分钟内、status=normal；撤回后正文不可搜、不进 LLM 上下文，但时间线保留「（已撤回）」占位
- 删除：任意角色可删（含系统消息）；软删（deleted）——主聊天移除、回忆/搜索/摘要均过滤；DB 保留行保 id 稳定
- 取消流式：本轮用户句 status=failed + 「（未送达）」标记；failed 在 GUI 展示（主聊天/回忆）但不可搜、不进 LLM 上下文
- 无 DB id 的瞬态标签（transient 提示等）无右键菜单

## 踩坑记录

- **SystemLabelWidget 原本无 message_id**：系统消息也落库（save=True），但 widget 不持 id 导致无法定位删除——补齐构造参数与回填（`_append_parsed_message` 的 save 回填逻辑对 system 分支同样生效）。
- **QMessageBox.question 在离屏测试需 patch**：`gui.QMessageBox.question = staticmethod(lambda *a, **k: QMB.StandardButton.Yes)`（warning 的既有 patch 先例扩展）。
- **撤回时间戳用 DB created_at 而非 widget 本地时间**：DB 是权威且与回忆浮层一致；格式 `%Y-%m-%d %H:%M:%S`（`datetime('now','localtime')`）。
