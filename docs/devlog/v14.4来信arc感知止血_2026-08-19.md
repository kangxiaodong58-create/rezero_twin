# v14.4 来信 arc 感知——帝国篇 OOC 止血（Step 0）

日期：2026-08-19
来源：场景化内容密度与篇章模版池研判报告（docs/design/场景化内容密度与篇章模版池研判_2026-08-19.md）§3.2 最高优先级漏洞

## 漏洞实锤

`letters.json` 40 条模板无 arc/recovery 字段，`evaluate_and_dispatch` 匹配维度只有
`bucket × sender × favor × 时段`（letter_manager L146-162）。帝国篇（recovery=0，
失忆蕾姆礼貌疏离）favor≥70 时命中 `days_3_7_rem_high_01`「没有您的日子蕾姆连呼吸
都困难」——与 `PromptBuilder._build_special_states` 注入的「失忆应温和但明显疏离」
**同屏冲突**：LLM 被告知疏离，模板来信却深情告白。

## 止血方案（最小补丁，不重写引擎）

1. **`LetterManager.evaluate_and_dispatch(..., arc="mansion_era")`**：模板 `arcs`
   字段过滤；**缺省 = ["mansion_era"]**（安全默认：内容默认宅邸专用，新 arc 内容
   必须显式声明；`"all"` 显式全 arc）。GUI 调用传 `engine.arc.value`。
2. **`content/letters.json`**：40 条既有模板显式标注 `"arcs": ["mansion_era"]`。
3. **新增 3 条帝国克制来信**（arcs:["empire_era"]，失忆疏离基调，与 Prompt 注入一致）：
   - `empire_rem_cross_01`（CROSS_PERIOD）「……啊，是那位客人。蕾姆刚好在整理走廊，您有什么事吗？」
   - `empire_rem_days_01`（DAYS_1_3）「……您又来了。蕾姆不记得您是谁，但宅邸确实安静了一阵子。」
   - `empire_ram_long_01`（LONG_ABSENCE）「哦？消失了这么久又出现的客人。拉姆不记得招待过您，不过……茶还是可以喝一杯的。」
4. **覆盖缺口**：帝国模板未覆盖 HALF_DAY/DAYS_3_7 桶与 ram/twins 发件人组合 →
   **克制静默**（不回落宅邸模板）——「触发必对、静默亦对」的设计。

## 踩坑记录（flaky 两连修）

1. **72h 桶边界浮点抖动**：`_state()` 默认 3 天（time.time() 两次调用间隔微秒）→
   hours_since 在 71.9999/72.0001 间抖动 → 落入 DAYS_3_7（帝国无模板）→ 测试空转。
   修正：默认 36h（稳定落 DAYS_1_3，两 arc 均有模板）。
2. **内容断言过严**：`days_1_3_ram_high_01`「拉姆还以为……茶已经泡好了」不含
   「客人/蕾姆」→ 断言 flaky。修正：放宽为 sender 合法 + 内容非空（触发本身是重点）。
3. **随机采样静默**：帝国 DAYS_1_3 仅 rem 模板，sender 采样 ram/twins → 静默（设计
   允许）。测试断言语义修正为「触发必疏离，静默亦可」。
