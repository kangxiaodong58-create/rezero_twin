# v14.2 引用回复

日期：2026-08-07
来源：V14.2 任务书（任意气泡可引用 → 输入区引用条 → 当前轮 Prompt 注入增强针对性）

## 修改内容

### `llm/bridge.py`（3 处）

1. `_build_messages(user_input, reply_to=None)`：reply_to 非空且 preview 非空 → system prompt 追加：
   ```
   ### 用户引用了你之前的话（仅本轮参考，请针对这段被引用的内容回应，不要复述引用标记）
   「{preview}」
   ```
   （沿用 v10.8.1 首轮氛围「仅本轮参考」先例；ephemeral——不进 history、不落库、不写 events）
2. `chat(..., reply_to=None)` / `chat_stream(..., reply_to=None)`：透传（默认 None，既有调用零感知）

### `gui.py`

1. **右键菜单**：`ChatMessageWidget`（引用，仅 `_status=='normal'`；撤回仅 user；删除恒有）与 `SystemLabelWidget`（引用+删除，仅带 DB id）新增 `quote_requested = Signal(int)`
2. **引用条**（input_layout 顶部，accent 左边线 + 淡金底，默认隐藏）：`↪ 回复 {sender}：{preview ≤30字}` + × 按钮
3. `_on_quote_request(message_id)`：`get_by_id` 校验 status——非 normal → transient「原消息已撤回，无法引用」；normal → 设 `self._quote` + 显示引用条
4. `_clear_quote()`：清状态 + 隐藏（× 按钮 / 发送后调用）
5. `_send_message`：发送时**再次校验**引用消息 status（期间可能被删/撤）→ 非 normal → transient「原消息已撤回，引用已取消」；normal → `reply_to = {id, preview}` → `_send_llm_stream(text, reply_to)`；引用一次性消费（无论成功与否清 `_quote`）
6. `LLMWorker(reply_to)` 透传 → `bot.chat_stream/chat(..., reply_to=...)`

### 测试（+5 用例）

- `tests/test_quote_reply.py`（新，4）：流式注入 / 非流式注入 / 无引用不注入（回归）/ 引用不进 history（用户句保持原文）
- `tests/test_ui_offscreen.py`（+1）：引用条显示与内容 / 已撤消息引用不覆盖 / × 取消 / 发送消费透传 reply_to + 一次性清除

## 行为变化声明

- 右键任意 normal 消息 → 引用条出现（摘要 ≤30 字）；发送后该轮 system prompt 含引用原文，双子回复针对性回应
- 引用不落库：用户句 content 保持原文；搜索/回忆无双份污染；事件记忆不写入
- 被引用消息在发起后、发送前被删/撤 → 明确提示并取消引用（不注入）
- 本地模板模式忽略引用（不注入，引用条照常消费清除）

## 真机操作步骤

1. 右键任意气泡 →「引用」→ 输入区出现「↪ 回复 …」金色条
2. （可选）× 取消引用
3. 输入并发送 → 双子回复应点题被引用内容
4. 引用后查看回忆/搜索——无双份记录
