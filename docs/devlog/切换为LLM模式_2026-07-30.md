# 切换为 LLM 桥接模式

## 已修改文件

### 1. `gui.py`

- 启动时自动加载项目目录下的 `.env`
- 默认模式从 `local` 改为 `llm`
- 使用 `ReZeroLLMBridge` 调用 Deepseek API 生成角色台词
- 保留硬状态机（好感度、拉姆阶段、独立度、记忆恢复、篇章）
- 每次对话后自动保存状态到 `data/memory.json`

### 2. `ReZeroTwin.spec`

- 将 `.env` 文件打包进 EXE
- 显式引入 `openai` 和 `dotenv` 依赖

## 重新打包

```powershell
cd C:\Users\11985\.qclaw\workspace\rezero_twin
pyinstaller ReZeroTwin.spec --clean
```

## 生成文件

```
dist\ReZeroTwin.exe
```

大小约 21MB（包含 Python 解释器、Tkinter、openai 依赖）。

## 运行方式

直接双击：

```
C:\Users\11985\.qclaw\workspace\rezero_twin\dist\ReZeroTwin.exe
```

启动后状态栏会显示：

```
LLM 桥接模式 | 篇章：mansion_era | 蕾姆好感：15/100 | 拉姆：可疑 | 独立度：0.25
```

## 注意事项

- `.env` 文件已随 EXE 打包，包含 `DEEPSEEK_API_KEY`
- 如需更新 API Key，需要修改 `.env` 后重新打包
- 每次 API 调用会消耗 Deepseek 账户余额
- 建议保留 `data/memory.json` 备份，避免误删导致记忆丢失

## 可用指令

| 指令 | 效果 |
|------|------|
| `/status` | 查看当前状态 |
| `/empire` | 切换帝国篇（失忆） |
| `/mansion` | 切换宅邸篇 |
| `/late` | 切换后期篇章 |
| `/recover 0.7` | 设置记忆恢复进度 |
| `/quit` 或 `退出` | 关闭程序 |
