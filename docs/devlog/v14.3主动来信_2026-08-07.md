## 行为变化声明

- 离线归来：<12h 同时段静默；<12h 跨时段 → 轻度关怀；12-24h → 中度；1-3 天 → 标准；3-7 天 → 挂念；≥7 天 → 深度关怀
- 发件人：favor<30 拉姆主导(65%)；30-69 平衡；≥70 蕾姆主导(55%)；twins 对话体 10-25%
- 冷却：首次启动不触发；距上封来信 ≥8h；每自然日 ≤1 封
- 来信 = 正常 assistant 消息（status=normal）：可右键删除、进回忆/搜索、进 LLM 上下文（用户首句回复时双子能接住来信话题）
- 不写好感/事件记忆；本地模式与 LLM 模式一致（纯模板）

## 踩坑记录

- **测试自撞冷却**：twins 采样循环里把 `last_letter_date` 设为与 `today_str` 相同 → 每日上限拦截 → 200 次全 None。修正：每次新建 state + 清空 last_letter_date。
- **回填断言时间敏感**：首版断言「推导 == 当前时段」依赖测试运行时刻（傍晚跑就推导「傍晚」≠硬编码「夜晚」）。修正：UPDATE created_at 为固定 10:00 再断言「上午」。
- **「当下时段」语义**：`WorldState.load_or_create` 已把 period 刷新为当前时段（与 last_period 分离）——判定无需额外处理。
