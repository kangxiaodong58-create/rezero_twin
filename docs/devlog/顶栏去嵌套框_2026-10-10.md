# 顶栏去嵌套框 + 删两处 app 图标（SPEC-20260922-29）施工记录 — 2026-10-10

## 根因（本次最值钱的一条）
**Qt 的 QSS「无选择器裸声明」会级联到该控件的所有子控件。**
`header_shell()/dock()/footer()/input_frame()/quote_bar()` 五个函数都返回裸声明，
而它们挂的容器**又都没有 objectName**（无法用选择器约束）⇒
顶栏里每个字段（标题/双子模式/氛围行/搜索框/按钮）**各自继承到** 1px 边框 + 圆角 ⇒
用户看到的「一整个长框里嵌套着一个又一个框」。

**对照组**：左导航有 `setObjectName("side_nav")` + `QFrame#side_nav {...}` ⇒ 子控件始终干净。
一窗口两种结果，机制坐实。

## 修法
1. 五个容器：`setObjectName(...)` + QSS 改 `QFrame#<obj> { ... }`；
2. 「双子模式」chip → 纯文字（`text_secondary`，无底色/描边/圆角，与氛围行同档）；
3. 删 `title_mark`（顶栏左上 app 图标）+ 删 `nav_twins`（左导航底部 app 图标）——用户点名要删的两张；
4. **防回弹守卫**：`test_container_qss_is_scoped` + 白名单（14 个叶子函数，写在测试文件里）。

## 教训
**给容器设样式表，永远带 `#objectName` 作用域。** 裸声明今天能跑，明天就会在某个子控件上长出多余的框——
而且它不会报错，只会"看起来怪"。守卫已把这条钉死。
