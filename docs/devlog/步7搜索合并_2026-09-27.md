## §1 做了什么

把**两条搜索入口各自一套的检索逻辑**收口到 `shared/search_service.py`：

| | 收口前 | 收口后 |
|---|---|---|
| 顶栏（`TwinChatApp._do_search`） | `self.conv_store.search(query, limit=10)` + 内联 `text[:60]…` | `self.search_service.search(query, limit=10)` + `format_preview(text)` |
| 浮层（`HistoryOverlay._do_search`） | `try: self._conv_store.search(keyword, limit=50) except: []` | `self._search_service.search(keyword, limit=50)`（兜底在服务层） |
| 数据层 | `ConversationStore.search()`（FTS5 快路径 + LIKE CJK 兜底）——**早已统一，未动** | 同左 |

改动面：新增 2 文件；`gui.py` 改 **5 处**（导入 1 / 服务构造 1 / 顶栏 2 / 浮层 2）。
