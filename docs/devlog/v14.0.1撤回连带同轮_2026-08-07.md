# v14.0.1 热修：撤回连带同轮助手回复

日期：2026-08-07
来源：V14.0 真机契约抽测 T2 暴露——撤回用户句后，同轮残留助手句仍含该信息（模型可据此答出已撤内容）

## 修改内容

### `shared/conversation_store.py`（+1 方法）

`recall_turn(message_id)`：撤回用户句并连带「同一次发送产生的助手回复」标为 recalled。

- 范围：`id > message_id` 且**下一条 user 消息之前**的 `rem/ram/assistant` 记录（system 不连带）
- **不连锁后续轮次**（上界 = 下一条 user；后续轮正常保留）
- 返回全部被标 recalled 的 id（含用户句）
- 语义收窄版确认（用户拍板）：用户句与同轮蕾姆/拉姆泡（通常 1~2 条）均走 recalled 占位（时间线保留），不做成「清空半个会话」

### `gui.py`（1 处）

`_on_recall_request`：`update_status` → `recall_turn`；遍历 `_mark_widget_recalled` 给同轮助手 widget 置「（已撤回）」占位；`_prune_bridge_history` 照旧。

### 测试（+2 用例，`tests/test_message_status.py`）

- `test_recall_turn_links_same_turn`：连带范围（用户句+同轮助手 recalled；后续轮 normal）+ system 不连带
- `test_recall_turn_history_clean`：撤后 history 不含用户原文与同轮助手原文（后续轮保留）

## 行为变化声明

- 撤回 = 该轮对话作废：用户句 + 同轮助手回复全部 recalled 占位，`_restore_history_from_store` 后两边均退出 LLM 上下文
- 3 分钟窗口、删除语义、failed 态、V14.0 三条查询过滤差全部不变
