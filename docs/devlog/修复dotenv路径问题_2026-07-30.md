# 修复 .env 加载路径问题

## 现象

新开的 PowerShell 中运行：

```powershell
python main.py --mode llm
```

报错：
```
ValueError: 未提供 DEEPSEEK_API_KEY。请在 .env 文件中设置或传入环境变量。
```

但 `.env` 文件确实存在于项目根目录，并且 Key 已写入。

## 根因

`llm/bridge.py` 中调用的是无参 `load_dotenv()`，它会查找 **当前工作目录** 下的 `.env`。如果用户通过不同路径或方式启动，`load_dotenv()` 可能找不到项目根目录的 `.env`。

## 修复

改为显式加载脚本所在目录（即项目根目录）的 `.env`：

```python
_ENV_PATH = os.path.join(_PROJECT_ROOT, ".env")
load_dotenv(_ENV_PATH)
```

这样无论从哪里启动，都能正确读取 `rezero_twin\.env`。

```powershell
python main.py --mode llm
```
