## §1 问题定位

「生硬」两个根因（`gui.py:267` 旧样式）：

```python
hit_style = f"background-color: {COLORS['search_hit']}; color: #1a1a1a;"
#                                  ↑ 不透明亮黄 #FFEB3B      ↑ 强制近黑字
```

且**同一个单值样式被两个底色完全不同的表面共用**：聊天区是**浅底气泡**（`rem/ram_bubble` 半透明叠在
`chat_surface` 浅底上）、历史浮层是**深底卡片**（`bg_surface_2 rgba(34,39,61,0.84)`）——深底上打满亮黄
= 最刺眼的一处。

## §2 改了什么

| 项 | 旧 | 新 |
|---|---|---|
| token | `search_hit: "#FFEB3B"`（单值） | 四键扁平：`search_hit_light_bg/_fg` · `search_hit_dark_bg/_fg` |
| 浅档（气泡） | 不透明黄底 + 黑字 | `rgba(255,205,96,0.42)` + 下划线，**不覆盖文字色** |

| 调用点 | 3 处（`:1357` `:1397` `:2475`） | 浮层 2 处传 `surface="dark"`；`highlight_hits` 保持默认 |
