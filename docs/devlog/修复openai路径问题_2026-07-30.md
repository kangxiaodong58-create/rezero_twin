# 修复 openai 导入路径问题

## 现象

在同一 PowerShell 终端中：
- `python -c "from openai import OpenAI"` 报 `ModuleNotFoundError`
- `python -m pip install openai` 显示 `Requirement already satisfied`，但指向的是用户目录
  `<用户目录>\AppData\Roaming\Python\Python311\site-packages`

## 根因

当前使用的 Python 解释器是：
`D:\Q-claw\QClaw\v0.2.35.624\resources\python\python.exe`

该解释器在通过 `python -m pip` 安装时，默认把包装到了用户 site-packages；但运行 `python` 时，实际 `sys.path` 没有正确加载用户 site-packages（可能是 OpenClaw 环境隔离或 `PYTHONNOUSERSITE` 等设置导致）。

## 修复方式

使用当前解释器自带 site-packages 重新安装 openai，不使用 `--user`：

```powershell
python -m pip install --force-reinstall --no-user openai python-dotenv
```

## 验证

```powershell
cd <项目根目录>
python main.py --mode llm
```

输出：
```
Re:Zero 双子系统已启动（LLM 桥接模式）
输入 status 查看硬状态 | empire / mansion / recover 0.7 切换状态 | quit 退出

小东：
```

程序已正常启动，openai 导入问题已解决。
