# v14.1 搜索命中词临时黄高亮

日期：2026-08-07
来源：V14.1 任务书（搜索增强：命中词正文黄底高亮 + 取消即清除；纯 UI 临时态）

## 修改内容

### `gui.py`

1. **模块级纯函数 `highlight_plain_text(text, keyword) -> str`**：`html.escape` 全文 → 转义后精确匹配关键词 → `<span style="background-color:#FFEB3B; color:#1a1a1a;">` 包装。多命中全部标黄；空 keyword/未命中返回 escape 原文。**防注入：先 escape 再高亮**（命中词的转义形态与原文一致，切片包裹安全）。
2. **`COLORS['search_hit'] = '#FFEB3B'`**。
3. **`TwinChatApp.highlight_hits(keyword)`**：遍历 `chat_layout` 可见 widget——仅 `ChatMessageWidget` 且 `message_id` 且 `_status=='normal'`（recalled 占位无原文 / failed 不命中搜索 / deleted 已移除）；原文取 `conv_store.get_by_id`（DB 权威）；`label.setText(html)` + 原文存 `w._search_hit_text`。
4. **`TwinChatApp.clear_all_highlights()`**：遍历恢复原文 + 删留存（幂等）。
5. **挂载点**：
   - 顶栏 `_do_search`：先 `clear_all_highlights()` → `highlight_hits(query)` → `_locate_message(results[0]["id"])`（**补此前「搜索不滚动」缺口**：现在搜索自动滚动定位第一条）
   - 顶栏搜索框 `textChanged` → `_on_top_search_changed`：清空 → clear
   - `_load_history` 末尾：clear（历史重载防残留）
   - `_close_history`：clear（关浮层即清）
6. **回忆浮层**：`HistoryItemWidget(record, keyword="")`——preview 摘要与展开全文在构造期用 `highlight_plain_text` 渲染；`_load_data(records, keyword)` 透传；浮层 widget 随列表重建销毁，无需额外 clear。

### `tests/test_ui_offscreen.py`（+1 用例）

`test_search_highlight_v141`：纯函数 6 断言（中文命中 / 多命中全黄 / `<b>` 转义防注入 / 空词原样 / 未命中原样）+ widget 级高亮→clear 往返 + recalled 占位不参与。

## 踩坑记录

- **patch 误删函数体**：`_rgba_to_qcolor` 的替换把原函数体（`s = rgba_str.strip()...`）错位进新函数尾部成死代码——立即重读修复（错位后 `_rgba_to_qcolor` 返回 None 会导致 QPainter.fillRect 崩溃，属于必须当场修复的错误）。
- **测试 NameError**：`QLabel` 未在测试文件 import（顶部只有 os/sys）——补 `from PySide6.QtWidgets import QLabel`。
- **QLabel 富文本**：`setText` 含 `<span>` 时自动按 RichText 渲染（无需显式 setTextFormat），恢复原文 `setText(plain)` 即回 PlainText 形态。
