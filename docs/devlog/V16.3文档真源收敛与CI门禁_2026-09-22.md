新增 `scripts/verify_isolation.sh`（本地/CI 共用）：

```bash
bash scripts/verify_isolation.sh <被测命令...>
# 判据：跑完后 data/ 内文件集合的 (路径, mtime, size) 快照必须逐字节相同；非空差异 → 退出码 1
```

**正反双向验证**（本地实测）：

- 正向：`bash scripts/verify_isolation.sh env -u PYTHONPATH venv/Scripts/python.exe -m pytest tests/ -q` → 295 passed + `✅ 数据隔离校验通过`
- 反向：故意在 `data/` 写 `__isolation_probe.tmp` → `❌ 数据隔离校验失败` 并打印 before/after 差异 → 清理探针 ✅

**未验证项（诚实登记）**：GitHub Actions 首跑未在本地验证（无 Linux runner）。`ci.yml` 的 YAML 结构经人眼校对，但 apt 包列表 / PySide6 在 runner 上的 offscreen 可用性**可能需要一轮修红**——这正是 SPEC 风险段预留的预算。若 Qt 装不上，退化为「非 GUI 子集 + 结构守卫 + 隔离校验」。
