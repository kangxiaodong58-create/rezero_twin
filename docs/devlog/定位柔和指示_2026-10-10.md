# 定位指示「柔和档」（SPEC-20260922-33）施工记录 — 2026-10-10

## 口径是怎么收敛的（三次迭代，一次比一次准）
1. **SPEC-23 原始设计**：定位闪光 α=0.55 ⇒ 用户真机：**太突兀** ✗；
2. **SPEC-32**：按当时字面要求**全关** ⇒ 用户：**完全没指示也不行** ✗；
3. **SPEC-33（本轮）**：用户一句话给全了口径 —— 「**不是不需要视觉聚焦，只是不要太突兀**」⇒ α=0.16 + 1px 细描边 ✓。

**教训**：观感类反馈里的「不要 X」往往等于「不要 X 的**那个强度**」，不等于「不要 X」。
拿到这类反馈时，**先给档位对照图**（本次四档 0.55 / 0.16 / 0.26 + 正常），让用户点档，比来回全开/全关快得多。

## 技术要点：描边为什么这次可行
SPEC-23 当年实测"描边会挤布局"⇒ 否决。本轮复核发现：当年测的是**新增**边框（原本无边框 ⇒ 尺寸变化）；
现在三角色气泡**本来就有 1px 角色描边**（SPEC-31 统一后）⇒ 闪光描边**同宽（1px）替换** ⇒
`widget.sizeHint / size / label.sizeHint` 三者在施加前后**完全一致**（探针实测）。

## 防线
用例 `test_locate_highlight_is_soft` 锁两件事：**α ≤ 0.20**（防突兀回弹）+ **描边必须 1px**（防布局抖动回弹）。
