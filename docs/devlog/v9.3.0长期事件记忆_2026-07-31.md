## 设计

重要时刻由状态机规则认定（零 API、确定性），不依赖 LLM 摘要。
9 类事件：name_first / favor_up / locked / ram_up / reunion / oni / breaker / affirm / conflict。
容量 30，里程碑钉住（name_first/locked/reunion/breaker），其余 FIFO。

## 涉及文件

- `shared/state.py`：引擎 `events`/`turn_count`/`_add_event`/`_detect_events`（update 末尾调用）；TwinState 新增可选 `events` 字段；update/snapshot 均携带
- `shared/prompts.py`：「共同经历」小节（钉住 + 最近 ≤6 条），含「不要编造未列出的经历」约束
- `shared/memory_store.py`：defaults + `"events": []`
- `gui.py`：双模式恢复/持久化 events；顺带补上 user_name 持久化（名字事件去重的前提，此前 GUI 重启丢称呼）
- `tests/smoke_test.py`：+1 测试函数（6 断言），总计 10 项

未动：bridge.py（事件经 TwinState 自动流入）、main.py、本地模式台词逻辑。

## 验证结果

- 冒烟 10/10 通过（名字事件/跃迁事件/肯定事件/钉住淘汰/prompt 注入有无/持久化）
- 真实 API 抽查 3 次调用（约 ¥0.015）：
  「我叫小东」→ 记录 `第2次对话：用户第一次告知名字「小东」`；
  随后问「还记得我们第一次正式说话的时候吗？」→
  蕾姆回答「那天小东大人第一次告诉蕾姆您的名字」——**引用真实事件，不再编造**
- local 模式回归 + py_compile 通过
