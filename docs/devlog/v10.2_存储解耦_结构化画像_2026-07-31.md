# V10.2 存储解耦 + 结构化画像 — 2026-07-31

## 架构变更

```
用户输入 → HardStateEngine → TwinState
                              ↓
              Memory Orchestrator（新增）
              ├─ SQLite（完整流水，GUI 翻阅）
              └─ StructuredProfile（LLM 注入，受控）
                              ↓
                        PromptBuilder
                              ↓
                            LLM
```

## Phase A：SQLite ConversationStore

### 新增文件
- `shared/conversation_store.py`：SQLite + FTS5 全文搜索

### 改动文件
- `gui.py`：
  - `__init__`：初始化 `ConversationStore`，自动迁移旧 JSON 数据
  - `_append_parsed_message`：写 SQLite（不再维护内存 chat_history 列表）
  - `_load_history`：从 SQLite 分页读取 `get_recent(limit=30)`
  - `_save_state`：不再存 chat_history 到 JSON

### 效果
- 对话历史完全解耦：GUI 读 SQLite，LLM 只收最近 N 轮
- FTS5 全文搜索：`cs.search("托付")` 可检索任意历史消息
- 旧 JSON chat_history 首次启动时自动迁移，之后 JSON 只存硬状态

## Phase B：StructuredProfile

### 新增类
- `shared/state.py` → `StructuredProfile`（@dataclass）

```python
@dataclass
class StructuredProfile:
    user_name: str
    important_promises: List[str]    # 从 affirm 事件提取
    rem_favor: int
    independence: float
    locked: bool
    ram_stage: str
    key_moments: List[str]           # 从 locked/reunion/breaker 事件提取
```

### 改动
- `PromptBuilder.build(state, world, profile)`：新增 profile 参数
- `bridge.py._build_messages()`：调用 `StructuredProfile.from_engine(engine)` 并注入 prompt
- Prompt 新增 `### 结构化画像（长期记忆）` 小节
