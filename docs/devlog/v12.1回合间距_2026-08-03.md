# v12.1 对话回合视觉分组（同角色紧 · 换人松 · 阵营段落）

日期：2026-08-03
commit: `feat: V11.10–V12.1 解析舞台、流式分人、幕间卡、UI motion、回合间距`（c0683d6，V12.1 增量）
来源：V12.1 任务书——体验仍偏「消息列表」，用最小布局参数做出「对话回合感」

## 修改内容（仅 gui.py + CHANGELOG）

1. **基线 spacing 下调**：`chat_layout.setSpacing(md(12) → xs(4))`，回合关系全部由**本条外层 top margin** 表达。
2. **回合间距 helper**：`_turn_top_margin()`（O(1) 回看 `itemAt(count-2)`，判定顺序：首条→sm / 涉 system→sm / 同 speaker→xs / 涉 user→lg / 其余→md）+ `_apply_turn_rhythm()`（按 widget 类型只改 top margin，不碰 Bubble 内部）。
3. **streaming 无缝**：临时泡加 `objectName="__streaming_temp__"` 标记；正式泡插入时跳过临时泡判定（顶替零跳变）；多临时泡草稿间按标准换气。
4. **历史自动应用**：`_load_history` 走 `_append_parsed_message` 单点，30 条批量自动带节奏（与 `animate=False` 正交）。

## 验证结果

- 离屏用例 17/17（五档间距、临时泡标记、顶替零跳变、删泡不变、85 条裁剪后判定仍正确）
- 冒烟 34/34；EXE 已重新打包；真机观感确认通过

## 行为变化声明

- 间距节奏：同角色 ≈13px / 换角色 ≈21px / 阵营 ≈25px / system 中性 ≈17px
- 回合间距是布局属性，不受 `REZERO_DISABLE_UI_MOTION` 控制（关动效后回合感仍在）

## 踩坑记录（重要）

- **insertWidget 之后再取 count-2 = 取到自己**：`_append_parsed_message` 里先 `insertWidget` 后调用间距计算，`chat_layout.count()-2` 指向的是**刚插入的 widget 自己**（ChatMessageWidget 有 `self.role` → 永远命中"同角色"→ 全部 xs=4）。离屏用例首轮 7/17 暴露。修复：**插入前计算**（此时布局最后一条才是真正的上一条）。streaming 泡因 `__streaming_temp__` 跳过逻辑恰好免疫，正式泡全灭。
- 教训：**任何"取布局上一条"的逻辑必须在 insertWidget 之前做**，或把"自己"排除在判定之外。已沉淀至 skill。
